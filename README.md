# Sistem Perpustakaan Digital Kampus (app-perpustakaan)

Aplikasi web berbasis Laravel 12 yang dirancang untuk membantu pengelolaan data katalog buku, manajemen anggota, serta pencatatan transaksi peminjaman buku perpustakaan kampus secara digital dan terstruktur.

---

## Cara Menjalankan Project Secara Lokal

   ```bash
   git clone -b dev [https://github.com/safiranadya/app-perpustakaan.git](https://github.com/safiranadya/app-perpustakaan.git)
   cd app-perpustakaan
